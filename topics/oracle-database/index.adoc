Oracle Database is a database commonly used for running online
transaction processing (OLTP), data warehousing (DW) and mixed (OLTP &
DW) database workloads. Oracle Database is available by several service
providers on-prem, on-cloud, or as hybrid cloud installation. It may be
run on third party servers as well as on Oracle hardware (Exadata
on-prem, on Oracle Cloud or at Cloud at Customer).
