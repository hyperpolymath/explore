🐠 Babel is a compiler created by https://github.com/kittens[Sebastian
McKenzie] in 2014 to convert ES6 to ES5 (originally called 6to5). It has
since become a toolchain that enables developers to write any next
generation JavaScript and serves as a testing ground for proposals from
https://github.com/tc39[TC39], the technical committee that specifies
https://en.wikipedia.org/wiki/ECMAScript[ECMAScript]. Babel can also
convert https://facebook.github.io/jsx/[JSX syntax] and strip out type
annotations from both https://flow.org/[Flow] and
https://www.typescriptlang.org/[TypeScript]. Babel is built out of
plugins. Compose your own transformation pipeline using
https://www.npmjs.com/browse/keyword/babel-plugin[plugins written by the
community] or https://github.com/thejameskyle/babel-handbook[write your
own].
