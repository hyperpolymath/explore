Error (or uncertainty) propagation is the practice of analyzing and
accounting for the effect of numeric quantities’ uncertainties on the
results of functions that involve them.

When variables used in a function or mathematical operation have errors
(due to https://en.wikipedia.org/wiki/Observational_error[measurement
uncertainties],
https://en.wikipedia.org/wiki/Statistical_fluctuations[random
fluctuations], sample variance, etc.), error propagation can be used to
determine the resulting error of the function’s output.
