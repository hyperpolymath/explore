*Handlebars* is a simple templating language. It uses a template and an
input object to generate HTML or other text formats. Handlebars
templates look like regular text with embedded Handlebars expressions.
Handlebars is largely compatible with Mustache templates. In most cases
it is possible to swap out Mustache with Handlebars and continue using
your current templates. A handlebars expression is a "`\{\{`", some
contents, followed by a "`}}`". When the template is executed, these
expressions are replaced with values from an input object.
