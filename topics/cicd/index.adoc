*CI/CD* is a build automation strategy and part of DevOps

* *https://github.com/topics/continuous-integration[Continuous
integration]*: Frequent merging of several small changes into a main
branch.
* *https://github.com/topics/continuous-delivery[Continuous delivery]*:
When teams produce software in short cycles with high speed and
frequency so that reliable software can be released at any time, and
with a simple and repeatable deployment process when deciding to deploy.
* *https://github.com/topics/continuous-deployment[Continuous
deployment]*: When new software functionality is rolled out completely
automatically.
