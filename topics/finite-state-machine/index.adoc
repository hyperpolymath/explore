A *finite-state machine* (FSM), *finite-state automaton* (FSA), or
simply *state machine* is a mathematical
https://en.wikipedia.org/wiki/Model_of_computation[model of computation]
and an https://en.wikipedia.org/wiki/Abstract_machine[abstract machine]
that can be in exactly one of a finite number of states at any given
time. The FSM can change from one state to another in response to some
inputs; the change from one state to another is called a _transition_.
An FSM is defined by a list of its states, its initial state, and the
inputs that trigger each transition.

In computer science, FSM are widely used in modeling of application
behavior (https://en.wikipedia.org/wiki/Control_theory[control theory]),
design of https://en.wikipedia.org/wiki/Digital_electronics[hardware
digital systems],
https://github.com/topics/software-engineering[software engineering],
https://github.com/topics/compiler[compilers],
https://en.wikipedia.org/wiki/Network_protocol[network protocols], and
https://en.wikipedia.org/wiki/Computational_linguistics[computational
linguistics].
