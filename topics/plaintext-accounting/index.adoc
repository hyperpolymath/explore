*_Plain text accounting_* is a way of doing bookkeeping and accounting
with plain text files and scriptable, command-line-friendly software,
such as https://ledger-cli.org/[Ledger], https://hledger.org/[hledger],
or https://beancount.github.io/[Beancount]. Benefits include version
control, scriptability, data portability and privacy. See
https://plaintextaccounting.org and https://wiki.plaintextaccounting.org
for more details.

If you have a PTA-ish project on Github, consider adding the
`+plaintext-accounting+` (*) topic in your repo settings.

Some related topics:
https://github.com/topics/ledger-cli[`+ledger-cli+`],
https://github.com/topics/hledger[`+hledger+`],
https://github.com/topics/beancount[`+beancount+`].

'''''

(*) The de facto spelling on Github. Try to get repos to switch to the
idiomatic `+#plaintextaccounting+` if you wish!
