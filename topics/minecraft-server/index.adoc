A Minecraft server is a player-owned or business-owned multiplayer game
server for the 2009 Mojang Studios video game Minecraft. In this
context, the term "`server`" often colloquially refers to a network of
connected servers, rather than a single machine. Players can start their
own server either by setting one up on a computer using software
provided by Mojang, or by using a hosting provider so they can have
their server run on dedicated machines with guaranteed uptime.
