As an Internet marketing strategy, search engine optimization considers
how search engines work, the computer-programmed algorithms that dictate
search engine behavior, what people search for, the actual search terms
or keywords typed into search engines, and which search engines are
preferred by their targeted audience. SEO is performed because a website
will receive more visitors from a search engine when websites rank
higher on the search engine results page (SERP). These visitors can then
potentially be converted into customers.
