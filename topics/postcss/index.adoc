*PostCSS* is a tool for transforming CSS with JavaScript. It can be used
to develop a template language such as Sass and LESS. The PostCSS core
consists of: * CSS parser that generates an
link:/topics/abstract-syntax-tree[abstract syntax tree] * Set of classes
that comprises the tree * CSS generator that generates a CSS line for
the object tree * Code map generator for the CSS changes made#

There are official tools making it possible to use PostCSS with build
systems such as link:/topics/webpack[Webpack], link:/topics/gulp[Gulp],
and link:/topics/grunt[Grunt]. There is also a console interface
available. link:/topics/browserify[Browserify] or Webpack can be used to
open PostCSS in a browser.

The complete plugin list can be found on postcss.parts, with some
examples listed below. * link:/topics/autoprefixer[Autoprefixer] to add
and clear link:/topics/vendor-prefix[browser prefixes]. *
link:/topics/css-modules[CSS Modules] to get
link:/topics/css-selectors[CSS selectors] isolated and code organized.
It is supplied as part of Webpack. * link:/topics/stylelint[stylelint]
to analyze CSS code for mistakes and check style consistency. * stylefmt
fixes the CSS code according to the stylelint settings. * PreCSS to
perform some Sass/Less preprocessing functions. * postcss-preset-env to
emulate features from unfinished CSS specification drafts. *
link:/topics/cssnano[cssnano] to make CSS smaller in size by getting rid
of the spaces and rewriting the code. * link:/RTLCSS[RTLCSS] to change
CSS code so that the design should be suitable for right-to-left writing
(such is applied in Arabic and Hebrew). * postcss-assets,
postcss-inline-svg and postcss-sprites to work with graphics.
