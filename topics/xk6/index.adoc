https://github.com/grafana/xk6[xk6] is one of the core components of the
https://github.com/grafana/k6[Grafana k6] performance testing ecosystem.
Developers can use the `+xk6+` command-line tool to customize k6,
allowing them to add features, protocols, or output options to meet
specific testing needs.

k6 extensions are located in repositories named `+xk6-*+` and tagged
with the `+xk6+` topic.
